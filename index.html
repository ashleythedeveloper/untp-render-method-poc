UNTP render method proof of concept

This page renders UN Transparency Protocol credentials with the W3C html render suite as specified in Verifiable Credential Rendering Methods v1.0, Working Draft of 6 October 2026, plus two extensions: host-mediated links and host-prefetched images. The activity panel shows each step.

These are unsigned sample credentials. Signature verification is out of scope for this proof of concept.

WD
Behaviour the Working Draft specifies.
Host-mediated links
A click in the credential sends the host a JSON Pointer into the credential; the host resolves it and decides what to open. The frame never navigates.
Host-prefetched images
The host fetches only the images the issuer lists in renderResource, checks each digest and passes them to the template in a separate data block. The credential is never modified.
