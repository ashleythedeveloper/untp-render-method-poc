Proof-of-concept render vocabulary

These terms are extensions used by this proof of concept only. They are not part of the W3C Verifiable Credential Rendering Methods Working Draft or of the UN Transparency Protocol vocabulary.

renderResource

An optional property of a SuiteRenderMethod, next to renderProperty. Its value is a list of JSON Pointers (RFC 6901) into the credential. Each pointer names an object, such as a product image link, that the issuer allows the host to fetch on the template's behalf. The host fetches a named object only when it has an https: URL in linkURL (or id), a digestMultibase and an image/* mediaType, and only when its bytes match the digest. When renderProperty is present, a pointer outside it is ignored. The verified images reach the template in a separate <script name="resources" type="application/json"> data block, keyed by the URL in the credential; the credential itself is not modified.

The PoC credentials define the term with an inline context entry: {"renderResource": {"@id": ".../vocab#renderResource", "@container": "@list"}}.
